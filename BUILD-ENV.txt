CMake 说明（重要）
------------------
Android SDK 自带的 CMake 3.22.1 / 3.31.6 / 4.1.2 在本机 Windows 上执行
C++ 编译器识别时崩溃（退出码 -1073740791 / 0xC0000409），不能用于构建。
因此本工程通过 local.properties 的 cmake.dir 固定使用官方 Kitware CMake 4.3.1。
app/build.gradle.kts 不再写死 cmake version。

构建命令（两次全 clean、无缓存、非并行）
----------------------------------------
gradlew.bat --no-daemon --no-parallel --no-build-cache clean :app:assembleRelease --rerun-tasks

签名命令（固定 release.keystore；v2 only；不写时间戳）
------------------------------------------------------
apksigner sign --ks <release.keystore> --ks-key-alias forensic-release ^
  --v1-signing-enabled false --v2-signing-enabled true ^
  --v3-signing-enabled false --v4-signing-enabled false <apk>

复算与验收
----------
1. 从 forensic-camera-src-v3.4.5.zip 解压到纯 ASCII 路径。
2. 按本文件安装固定工具链，写 local.properties：
     sdk.dir=<SDK>
     cmake.dir=<cmake-4.3.1>\cmake\data
3. 执行 repro_build.ps1（默认会比对上述 unsigned/signed 哈希与证书指纹）。
4. 交付 APK 的签名证书必须等于
   09bfeeb368b715d6591ce1a795b916b08cbd493d43e05131b1cdbde748e00c1e。
5. 链上 register 时记录：
   release vc=11 apk=<signed SHA-256> cert=<证书指纹> unsigned=<unsigned SHA-256>

限制声明
--------
- debug 构建不保证可复现（D8 per-class dexing 与签名/打包差异），仅用于功能调试，
  不得作为取证交付物。
- 私有 release.keystore 与 keystore-info.txt 不随源码分发；第三方以交付 APK 的
  apksigner 证书指纹与链上 register 记录比对完成身份闭环。
- 构建路径、工具链版本、并行/缓存策略任一变化都可能改变 APK 字节。
